# lojaroupa 
# Software em C para um sistema de venda de uma loja de roupa chamada Casuality

## Funcionalidades - O sistema suportará as seguintes funcoes

### Cadastro de usuário - Cadastro de nome, CPF, email

### Carrinho de compras - Soma os valores de acordo com a adicao de pecas pelo usuário, de acordo com um um código de identificacao de código

### Pagamento - Suporte a pagamentos via Pix, cartão

### Relatório - Balanco de vendas itens
